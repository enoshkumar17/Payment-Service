Integrating with PayPlatform Backend

How external applications (like MovieHub or FoodBox) connect to this reusable payment engine.

1

Register Your Platform

Admins create a merchant profile and receive a unique mch_live_... API key once.

2

Send the x-api-key in Request Headers

Every transaction request includes the platform key to identify and associate the transaction.

POST /api/v1/transactions/new-transaction
Host: localhost:3500
x-api-key: mch_live_4b8f72a1e0c395d821f06a92cb71a39d84e1a0b3f5c9e2d1
Authorization: Bearer <customer_jwt_token>
Content-Type: application/json

{
  "fromAccount": "66e1b7c12f4a5c0012a4e111",
  "toAccount": "66e1b7c12f4a5c0012a4e222",
  "amount": 250,
  "idempotencyKey": "order_moviehub_ticket_9921"
}
3

Dual-Layer Security Verification

The backend verifies that the Merchant Key is active, AND verifies that the Customer Token actually owns the fromAccount. Merchants cannot debit arbitrary accounts.

4

State Machine & Ledger Execution

Transactions enter PENDING, acquire a row write lock on the source account, transition to PROCESSING, insert double-entry ledger debit and credit entries, and transition atomically to SUCCEEDED.
